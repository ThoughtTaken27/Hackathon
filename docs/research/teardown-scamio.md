# Teardown: Bitdefender Scamio (Finance runner-up) (Nov 13 2026)
Bitdefender · free with signup · launched Dec 2023 (press release, snippet only: https://www.bitdefender.com/news/bitdefender-launches-scamio-a-powerful-scam-detection-service-driven-by-artificial-intelligence.html)

- **Flow:** paste text, email, link, image or QR code into a chat → verdict + advice. One review says it gives the verdict but not the reason (https://gizmodo.com.au/?p=1925581, snippet only).
- **Trust:** no published accuracy numbers.
- **Weakness:** a chatbot wrapper. A free frontier chatbot does the same, so a weekend rebuild adds little unless it measures drift on modern scams.
- **Implication:** the Finance idea's only defensible edge would be the measurement (2012-trained model vs 2020s scams). The brief itself suggests that, so many teams will do it.
