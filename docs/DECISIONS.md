# Decisions

_Every teammate's Claude session reads this before working. Kettle decisions were made unattended by the stage-2 session on Sat Nov 14, 2026 (09:31–10:30 CT) from the probes in `docs/research/kettle/probes/`. Parth (lead) confirms or reverses them; each row says how._

| Item | Decision |
| --- | --- |
| Track | **AI + Health** ("catch a health problem sooner, or manage an ongoing one better") |
| Idea | **Kettle**: a laptop already in the kitchen listens in 10-second windows, turns household sounds into a calm day timeline for a distant adult child, keeps no audio and no words, and publishes its own missed-activity and false-alarm rates |
| Problem statement (one sentence) | An adult child who lives far from a parent with early memory loss can't tell whether today was a normal day without calling to check up or installing cameras, and the sensor kits that answer this cost £/$ hundreds, make the parent feel watched, and publish no accuracy at all |
| Target user (specific person) | Meera, 34, 300 miles from her father Ravi, 79, early memory loss, lives alone (invented persona). Second user: Ravi himself, who sees the same screen and can pause it |
| MVP flow (max 5 steps) | 1 Ravi presses "Yes, start" on the kitchen laptop → 2 Kettle hears 10-s windows and labels them (cooking, dishes, TV…) with the sounds behind each → 3 Meera opens "Dad's kitchen today": heartbeat, one-line summary, day bar → 4 her rule "kitchen activity by 10:00 AM" shows met / not yet / missed / can't tell → 5 "How sure is Kettle?" shows the measured misses and false alarms |
| Out of scope (until MVP works) | Fall/emergency detection, smoke/CO/glass, any speech recognition, accounts, cloud, push notifications, learned routines, native apps, phone as the kitchen mic (needs HTTPS) |
| Primary metric | Macro F1 over the 9 SINS activities (the DCASE metric), with per-activity **missed** (FN) and **false-alarm** (FP) counts and N, 95% CIs by session bootstrap |
| Test set plan + who labels | Headline: official DCASE 2018 Task 5 eval set (labels by the dataset authors, public in Zenodo 1964758), a fixed random sample, run once with the frozen model. Honest worst slice: own-kitchen recordings labelled by a Lane A teammate who did not write the code |
| Code home (Colab / repo / both) | GitHub repo; `pip install -r requirements.txt && python app.py`; demo mode needs no mic, no network, no keys |
| UI | One FastAPI app serving plain HTML/CSS/vanilla JS: `/kitchen` (parent's device), `/` (caregiver view), `/how-sure` (numbers). No build step |
| LLM / vision provider | **None at runtime.** No LLM anywhere in the product; summaries are templates. AI tools are used only to write code (logged in `AI-USAGE-LOG.md`) |
