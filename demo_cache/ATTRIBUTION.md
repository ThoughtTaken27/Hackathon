# Sample-day audio: attribution

`clips/*.flac` are 90 ten-second clips (channel 0 of sensor node DevNode1, 16 kHz mono) from the
**SINS / DCASE 2018 Task 5 development dataset**:

- G. Dekkers, S. Lauwereins, B. Thoen, M. W. Adhana, H. Brouckxon, T. van Waterschoot, B. Vanrumste,
  M. Verhelst, P. Karsmakers, "The SINS database for detection of daily activities in a home environment
  using an acoustic sensor network", DCASE 2017 Workshop. KU Leuven ADVISE.
- Data: https://doi.org/10.5281/zenodo.1247102 · Licence: **CC BY-NC 4.0** (attribution, non-commercial).
- Changes: we kept channel 0 only and converted WAV to FLAC (lossless). File names are unchanged.

They come from 9 whole recording sessions (one per activity) that are **held out of Kettle's training**,
so the sample days and the golden "Try your own sound" clip are out-of-sample for the shipped model
(`data/meta/plan.json` lists the sessions). The person recorded is one adult in a vacation home; the clips
are not of anyone we know, and Kettle's sample days say so on screen.

`try/white-noise.wav` and `try/silence.wav` are generated by us (seeded noise and zeros); `try/not-audio.txt`
is a text file used to test the "That isn't audio" screen.
